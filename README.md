- **Release & Unlock Times** — when GTA 6 unlocks in your city, from New Zealand to Los Angeles
- **Editions Compared** — Standard vs Ultimate, only confirmed contents
- **Preload Guide** — PS5 and Xbox steps, storage tips, unlock behaviour
- **Hindi FAQ** — GTA 6 के सवाल, आसान हिन्दी में जवाब
- **PC Release Tracker** — no official date yet; official statements vs reports, kept separate

Static HTML/CSS/JS, no build step. Every factual page carries a "Last updated · Sources" line.
